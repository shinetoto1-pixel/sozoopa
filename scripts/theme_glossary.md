# 뉴스 패턴 → 테마 매핑 참고자료

검증된(또는 사용자가 교정해준) "이런 뉴스가 나오면 이 테마다" 매핑을 쌓아가는 파일.
새로 테마를 판단할 때 이 목록을 먼저 참고하고, 사용자가 판단을 수정해주면 여기에 추가한다.

형식: `뉴스 패턴 → 테마 (사유)`

---

(아직 축적된 항목 없음 — 실제 사례가 생길 때마다 추가)

예시 (아직 검증 안 됨, 형식 참고용):
- 폭염 + 정전/전력수급 뉴스 → 스마트그리드/전력설비 (폭염 자체가 아니라 전력 인프라 이슈로 연결)
- 한파 뉴스 → 도시가스/난방 관련

---

## 기각 사례 — 배경 서사인데 테마로 착각했던 것들

`news_monitoring_priority.md`의 Phase 2 - 5번 기준("단기 촉매성 검증") 관련. 오늘의 구체적 사건 없이
계절성·트렌드·구조적 산업 이야기만으로 테마를 잡으려 했다가 반려된 사례를 쌓아서 판별 감각을 키운다.

형식: `기각된 테마 후보 (왜 배경 서사였는지 — 오늘 아니어도 항상 쓸 수 있었던 이유)`

(아직 축적된 항목 없음 — 실제 사례가 생길 때마다 추가)

예시 (형식 참고용, 아직 실제 기각 사례 아님):
- "폭염이라 제습기/여름가전 잘 팔릴 것" (계절 내내 거의 매일 동일하게 쓸 수 있는 이야기 — 특정 날짜의 구체적 사건이 없었음)
